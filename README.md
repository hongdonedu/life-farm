# 꼬물꼬물 한살이 농장

2022 개정 교육과정 **초등 3학년 1학기 과학 4. 생물의 한살이**를 위한 관찰·실험 농장 웹 게임입니다.

- **나비 사육장** [4과04-01] — 사육 준비물과 약속, 32일 관찰 달력(돌보기·돋보기·자), 관찰 기록장(글+그림), 한살이 포트폴리오
- **씨앗 실험실** [4과04-02] — 씨가 싹 트는 조건(물, 알맞은 온도) 실험: 다르게 할 조건·같게 할 조건, 예상 → 관찰 → 설명
- **쑥쑥 텃밭** [4과04-02] — 식물이 자라는 조건(물, 햇빛) 실험 설계와 10일 관찰
- **한살이 도감관** [4과04-03] — 알을 낳는 동물·새끼를 낳는 동물, 한해살이·여러해살이, 계절 비교
- **한살이 박람회** [4과04-03] — 한살이 소개 카드 만들기와 전시
- **스마트 팜** (진로) — 센서 규칙으로 물·빛·온도 맞추기, 스마트 팜 전문가
- **농장 일지**(포트폴리오 인쇄) · **마무리 퀴즈** · **명예 농부 수료증** · **선생님 모드**(비밀번호 2022)

## 여는 방법
- 인터넷: GitHub Pages 주소로 열기: https://hongdonmax.github.io/life-farm/
- 내 컴퓨터: `index.html`을 더블클릭 (소개 카드 그림 저장만 웹 주소에서 돼요)

## 폴더
| 경로 | 내용 |
|---|---|
| `index.html`, `css/`, `js/` | 게임 (`js/data.js`에 학습 내용 데이터) |
| `assets/` | ChatGPT로 만든 그림 (시트 7장 + 배경) |
| `worksheet/` | A4 3쪽 활동지 |
| `guide/` | 제작 가이드 (AI 코딩 프롬프트, ChatGPT 그림 프롬프트, 배포 방법) |
| `video/` | 제작 과정 영상 |

학습 내용은 교사용 지도서(3-1-4 생물의 한살이)를 기준으로 했습니다. 진행 기록은 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.
